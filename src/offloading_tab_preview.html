🤖 AI Reads Offload Sheet Automatically

Tapping Camera or Upload sends the image to Claude AI. It reads Arrival Time, Completed Time, and confirms TMW # — same as the Loading tab scan. No manual entry needed.

🔗 TMW # Carries Over From Loading Tab

The TMW # entered or auto-filled on the Loading tab is shown here as read-only reference — it links both tabs to the same load automatically.

⏱ Wait Time Calculation

Arrival Time and Completed Time allow the app to auto-calculate offload wait minutes — same logic as the Loading tab's offloadWaitMins field.

📐 Implementation Notes (for developer)

Add activeLoadSubTab state (loading | offloading). The two tab buttons toggle this state. Off Loading tab fields: offloadDate, offloadArrivalTime, offloadCompletedTime, offloadNote, offloadDispatchImage. TMW # is read-only on Off Loading tab — synced from the main form's tmwLoadNumber. AI scan on Off Loading tab calls same /api/ai-chat endpoint with a focused prompt: extract offload arrival time, completed time, confirm TMW #. All fields already exist on the form object (offloadArrivalTime, offloadCompletedTime, offloadWaitMins) — no DB schema changes needed.
